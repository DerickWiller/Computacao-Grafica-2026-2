Trabalhos práticos da disciplina de Computação Gráfica (UFG). O projeto é feito em HTML, CSS e JavaScript puro, sem dependências.

Para rodar é só abrir o `index.html` no navegador.

- A5: rasterização de retas (Analítico, DDA e Bresenham) e circunferência (Bresenham).
