# Computação Gráfica 2026/2

Trabalhos práticos da disciplina de Computação Gráfica (UFG). O projeto é feito em HTML, CSS e JavaScript puro, sem dependências.

Para rodar é só abrir o `index.html` no navegador.

## Atividades

- A5: rasterização de retas (Analítico, DDA e Bresenham) e circunferência (Bresenham).
- A6: polígonos com preenchimento por Varredura e BoundaryFill.
- A7: transformações geométricas (translação, escala e rotação) pelo teclado.
- A8: recorte de linhas (Cohen-Sutherland) e de polígonos (Sutherland-Hodgman) com a janela desenhada pelo mouse.
- A9: curvas de Bézier e B-Spline, com a quantidade de pontos de controle escolhida num diálogo e os pontos marcados pelo mouse.
- A10: modelagem de uma banqueta no Blender com primitivas, pivô, formas de representação, operações booleanas e varredura. O arquivo `.blend` e as capturas de tela ficam na pasta `a10`.
- A11: prática de cores, iluminação e sombreamento no Blender, com um plano, um cubo e uma esfera. O arquivo `.blend` e as imagens ficam na pasta `a11`.

Os relatórios de cada atividade ficam na pasta `relatorios`.
